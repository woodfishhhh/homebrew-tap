# Homebrew tap for Obituary

[Obituary](https://github.com/woodfishhhh/obituary) gives the files your AI agents leave behind a lifespan. When it runs out they go to a graveyard, and anything buried can be brought back for seven days.

```sh
brew install --cask woodfishhhh/tap/obituary
obit init
```

Upgrade with `brew upgrade --cask obituary`. The cask installs `obit` and `obitd` for Apple silicon and Intel Macs.

讣告：给 AI 留下的文件设寿命，到期进墓地，七天内随时复活。安装见上面两行命令，更多说明在 [obituary.woodfish.site](https://obituary.woodfish.site)。
